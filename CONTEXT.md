## Glossary

- **tool**: one self-contained calculator or plotter within the dashboard
  (e.g. "d-spacing calculator", "peak fitting viewer")
- **widget**: a UI control within a tool — slider, number input, dropdown
- **dashboard**: the main page listing all available tools
- **live update**: results recalculate as the user changes an input, no
  "submit" button needed
