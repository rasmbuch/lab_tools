# Lab Tools

Browser-based calculators for XFEL nanofocus experiments.

**[Live site](https://rasmbuch.github.io/lab_tools/)**

## Quick start

```bash
npm install
npm run dev
```

Opens at [localhost:5173](http://localhost:5173). Changes hot-reload.

## Build for production

```bash
npm run build
npm run preview   # check the build locally
```

Output lands in `dist/` -- serve it with any static file server.

## Type checking

```bash
npm run check
```
