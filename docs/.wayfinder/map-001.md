# Wayfinder Map: Lab Tools Dashboard

**GitHub:** rasmbuch/lab_tools#1
**Label:** `wayfinder:map`
**Status:** ACTIVE

## Destination

A locally-running browser dashboard with 3-5 interactive scientific tools
(calculators + plotters) that non-coding lab coworkers can open and use
immediately. Built well enough that it looks intentional, not generated.
The developer (PR) learns web fundamentals along the way.

## Notes

- Domain: crystallography, X-ray scattering, diffraction
- Developer has strong Python/numpy background, some prior Svelte exposure, learning senior-dev workflow (steering + reviewing, not writing every line)
- Skills to consult: `/grill-with-docs`, `/tdd`, `/prototype`
- Design skills: `/impeccable` (install: `npx impeccable install`), `/design` (Claude Design at claude.ai/design for mockups)
- Design reference: see DESIGN.md (Nolde Museum + Seaborn + Frans Hals Museum aesthetic)
- Pace: side project, no deadline — learning is a primary goal
- Anti-goal: avoid "AI slop" — every design choice should be deliberate
- This map doubles as a wayfinder tutorial — the first real use of the skill

- **Build a hello world** (#3) — Svelte 5 + Vite 8 + TypeScript 6 scaffold. Wavelength→energy converter as proof of concept. Dev server at localhost:5173, build clean, hot-reload working.
- **Design the dashboard layout** (#5) — Claude Design mockup accepted (2026-08-05). Deep ultramarine sidebar, warm off-white main area, Archivo + IBM Plex Mono typography, card grid with live mini-previews. Visual spec in `reference_from_claude_design/Lab Tools - 3 Split.dc.html`. Palette inspired by Emil Nolde painting. Attribution one-liner in design notes page.
- **First tool spec** (#6 grilling) — Energy/wavelength converter grilled (2026-08-05). Three fields with dropdown unit toggles: energy (eV/keV/MeV), wavelength (Å/nm/um), frequency (THz/EHz). No wavenumber. Default 9.7 keV, 4 sig figs, dash for invalid input, no range clamping. Physics ported from Python, not from mockup's JS. Mockup is visual spec only.
- **First tool build plan** (#6 build grilling) — Hash routing, no library. Component tree: App → Sidebar + Dashboard (generic ToolCard) + EnergyConverter. Internal eV, CODATA constants in `lib/constants.ts`. `on:input` + activeField pattern. CSS tokens in `app.css`, scoped styles, self-hosted fonts. Three stacked rows. Full shell built, other tools stubbed. Mobile deferred.

### #4: Define the first tools [grilling]
**Type:** grilling (HITL)
**Status:** CLOSED
**Blocks:** #5, #6

**Resolution:** Four tools for v1, ordered simple→complex (decided 2026-08-03):

1. **Energy/wavelength converter** — convert between eV, keV, Angstrom, nm,
   THz, cm⁻¹. Simplest possible tool; good scaffold warm-up.
2. **Intensity unit converter** — input W/cm², photon energy → output
   photons/nm²/pulse (and reverse). Bridges power-density and photon-fluence
   units scientists switch between constantly.
3. **Eta/eta-prime calculator** — port of `docs/xfel_calc.py`. Interactive
   sliders for pulse energy, photon energy, focal FWHM, pulse duration.
   Plotly plots for eta-vs-energy and focal-plane maps. The flagship tool.
4. **Solid angle calculator** — input active detector area + sample-detector
   distance → solid angle in steradians. Common geometry calculation at
   the beamline.

Deferred to v2: d-spacing/Bragg calculator, scattering geometry plotter,
peak fitting viewer.

### #6: Build the first tool end-to-end [grilling + task]
**Type:** grilling → task (HITL)
**Status:** CLOSED
**Blocked by:** #2, #4, #5

**Grilling resolution (2026-08-05):** Energy/wavelength converter. Three
input fields, each with a dropdown unit toggle (matching the select-style
from the mockup):

- **Energy:** eV / keV / MeV
- **Wavelength:** Å / nm / um
- **Frequency:** THz / EHz

Edit any field, the others update live. Default: 9.7 keV. 4 significant
figures. Dash for invalid input. No range clamping — works from IR to
gamma. No wavenumber (cm⁻¹ dropped). Physics from Python (`hc/λ`), not
from the mockup's JS. This tool establishes the Svelte component patterns
for all subsequent tools.

**Build grilling (2026-08-05):** Hash routing (`#/energy`, etc.) with
`hashchange` listener, no library. Component tree: App → Sidebar,
Dashboard (with generic ToolCard), EnergyConverter. Canonical internal
value in eV, constants in `src/lib/constants.ts` (CODATA 2018). Input via
`on:input` handlers tracking `activeField` + `rawInput` to avoid circular
updates; inactive fields show `$derived` formatted values. 4 sig figs,
no sci notation for 0.001–999999, uses × 10 superscript for larger/smaller.
Design tokens as CSS custom properties in `app.css`, scoped styles in
components. Self-hosted Archivo + IBM Plex Mono. Three stacked rows
(energy/wavelength/frequency) each with input + unit dropdown. Full sidebar
+ dashboard card grid built; other three tools stubbed with static formula
previews; Design notes placeholder. Mobile deferred.

**Build resolution (2026-08-05):** Implemented as specified. 14 files,
936 lines. Components: App (router shell), Sidebar, Dashboard, ToolCard,
EnergyConverter, Placeholder. Lib: constants.ts (CODATA 2018), convert.ts
(eV/wavelength/frequency conversions), format.ts (sig figs + × 10
superscript), router.ts (hash routing). Fonts self-hosted. Type-checks
clean (0 errors, 0 warnings).
