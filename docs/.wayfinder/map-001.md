# Wayfinder Map: Lab Tools Dashboard

**Label:** `wayfinder:map`
**Status:** ACTIVE

## Destination

A locally-running browser dashboard with 3-5 interactive scientific tools
(calculators + plotters) that non-coding lab coworkers can open and use
immediately. Built well enough that it looks intentional, not generated.
The developer (PR) learns web fundamentals along the way.

## Notes

- Domain: crystallography, X-ray scattering, diffraction
- Developer has strong Python/numpy background, some prior Svelte exposure, learning senior-dev workflow (steering + reviewing, not writing every line)
- Skills to consult: `/grill-with-docs`, `/tdd`, `/prototype`
- Design skills: `/impeccable` (install: `npx impeccable install`), `/design` (Claude Design at claude.ai/design for mockups)
- Design reference: see DESIGN.md (Nolde Museum + Seaborn + Frans Hals Museum aesthetic)
- Pace: side project, no deadline — learning is a primary goal
- Anti-goal: avoid "AI slop" — every design choice should be deliberate
- This map doubles as a wayfinder tutorial — the first real use of the skill

## Decisions so far

- **Choose the web tech stack** (TICKET-001) — Svelte + Vite + TypeScript + Plotly.js. Static site, no backend. PR has prior Svelte exposure; TS matches typed-Python style; Plotly handles scientific plots natively.
- **Define the first tools** (TICKET-002) — four tools for v1: (1) X-ray energy/wavelength converter, (2) intensity unit converter (W/cm² ↔ ph/nm² at given photon energy), (3) eta/eta-prime calculator (from xfel_calc.py), (4) solid angle calculator (detector area + distance → sr). Ordered simple→complex.

## Tickets

### TICKET-001: Choose the web tech stack [grilling]
**Type:** grilling (HITL)

**Resolution:** Svelte + Vite + TypeScript + Plotly.js. Static output (no

### TICKET-002: Define the first tools [grilling]
**Type:** grilling (HITL)
**Status:** CLOSED
**Blocks:** TICKET-004, TICKET-005

**Resolution:** Four tools for v1, ordered simple→complex (decided 2026-08-03):

1. **Energy/wavelength converter** — convert between eV, keV, Angstrom, nm,
   THz, cm⁻¹. Simplest possible tool; good scaffold warm-up.
2. **Intensity unit converter** — input W/cm², photon energy → output
   photons/nm²/pulse (and reverse). Bridges power-density and photon-fluence
   units scientists switch between constantly.
3. **Eta/eta-prime calculator** — port of `docs/xfel_calc.py`. Interactive
   sliders for pulse energy, photon energy, focal FWHM, pulse duration.
   Plotly plots for eta-vs-energy and focal-plane maps. The flagship tool.
4. **Solid angle calculator** — input active detector area + sample-detector
   distance → solid angle in steradians. Common geometry calculation at
   the beamline.

Deferred to v2: d-spacing/Bragg calculator, scattering geometry plotter,
peak fitting viewer.
