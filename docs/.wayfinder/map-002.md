## Destination

All 4 scientific tools live and deployed on GitHub Pages with a proper
Impressum, usable by coworkers via a bookmarkable URL. The energy/wavelength
converter (tool #1) is already built; this map covers the remaining 3 tools,
deployment, and legal compliance.

## Notes

- Domain: crystallography, X-ray scattering, XFEL nanofocus
- Tools #2 (intensity/fluence) and #3 (eta/eta-prime) share a beam geometry
  module with a Gaussian/flat-top mode toggle
- Tool #3 needs pre-computed X-ray cross-section data (xraylib → static JSON)
  for 6 elements: Au, Fe, Cu, Se, H, O
- Tool #3 includes 2D focal-plane heatmaps via Plotly.js
- Skills to consult: `/grill-me`, `/tdd`, `/prototype`, `/impeccable`
- Reference Python: `docs/xfel_calc.py`
- Design spec: `reference_from_claude_design/Lab Tools - 3 Split.dc.html`

## Decisions so far

- **Design the shared beam geometry module** (#8) — `src/lib/beam.ts`:
  `computeBeam(BeamParams): BeamResult`. SI at module boundary, lab-unit
  conversion in components. Spatial mode toggle: Gaussian
  (`A_eff = π FWHM_x FWHM_y / 4 ln 2`) vs flat-top elliptical
  (`A_eff = π/4 FWHM_x FWHM_y`). Temporal always Gaussian. Gaussian-only
  outputs: beam waists, Rayleigh lengths (`z_R = π w₀² / λ`).
- **Shared photon energy state** — `src/lib/stores.svelte.ts`:
  bidirectional `photonEnergy.eV` shared between tools #01 and #02 (and
  future tools). Overrides #8's original "no shared reactive state" decision.
