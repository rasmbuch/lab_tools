05

Design notes

The system

A fixed instrument frame — Nolde's deep ultramarine on the left, warm paper to the right — so tools swap without the page moving. One rule weight (1px, warm black at 14%) does all the dividing; there are no shadows, no rounded corners, no cards floating on cards.

Type: Archivo for everything structural — titles set tight and heavy, labels small and letterspaced — and IBM Plex Mono for every number you could copy into a paper. No serifs anywhere. Numbers are never set in the UI face — if it's a measurement, it's monospace.

Plots

The SVG axes copy your matplotlib style sheet on purpose: #f8f8f8 axes face, full box spines at 0.8pt, inward ticks on all four sides, no grid. A figure lifted from the browser into a slide should look like it came out of the notebook.

The focal map is a contour ladder rather than a pixel raster — same information, a tenth of the DOM, and it stays crisp on the tablet. It follows threshold_cmap: everything below η = 1 is desaturated to luminance, so the nonlinear core is the only colour on the screen — ultramarine through to cadmium yellow, straight off the watercolour.

Assumptions
  • Cross sections here are an interim two-parameter fit with edge jumps — enough to make the curves and edges honest in shape, not in the third digit. The xraylib port replaces them.
  • η′ uses one dominant core hole per element, as in xfel_calc.py; the per-shell table is a later addition.
  • Regime callout triggers on η crossing the threshold (a tweak, default 1).
  • Desktop-first. Below ~1100px the rail collapses to a top bar and the input column stacks above the plot — the plots are already viewBox-scaled, so they survive it.
