Lab Tools

Four interactive calculators for the nanofocus beamline. Each takes measured inputs and returns the quantities you need — live, as you type.

Tool 01

Energy & Wavelength

Convert freely between photon energy and wavelength. Supports eV, keV, Angstrom, nm, THz, and cm⁻¹ — all updating simultaneously as you type any one.

Intensity Units

Bridge the gap between power density (W/cm²) and photon fluence (photons/nm²) at any photon energy. The conversion everyone does on the back of an envelope, done properly.

Tool 03

Photons per Atom

The key figure of merit for nonlinear X-ray science: how many photons interact with each atom during a single pulse? When η exceeds 1, sequential multi-photon processes become probable.
